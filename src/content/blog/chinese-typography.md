中文和英文的排版，不是同一套参数换个字号。英文靠单词之间的空格切分节奏，中文是一块一块的方块字。行宽、行高、字重没调好，整页就会「糊」——字都认识，但读三行就想划走。

## 第一个数：行宽

西文有个经验值，每行 45 到 75 个字符。中文没有空格，换算过来大约是 **30 到 40 个汉字**。对应到 17px 的字号，就是 600px 上下的正文宽度。

超过这个数，眼睛回到行首时容易串行；低于 25 字，换行太频繁，节奏被切碎。所以正文容器写 `max-width: 36em` 就够了，别让它跟着屏幕一起撑满。

## 第二个数：行高

中文的字面率比英文高，同样的行高在中文里显得更挤。正文给到 `1.8` 到 `1.9` 之间比较舒服，段间距一个字高左右，节奏就顺了。

还有一条常被忽略：**网页不要首行缩进**。缩进是纸质书为了省纸形成的习惯，屏幕上有段间距做分隔，再缩进只会多出一个视觉缺口。

## 第三个数：字重

两档就够：正文 400，标题 600。三档以上，读者根本分不出来，反而让层次变乱。

```css
.prose {
	max-width: 36em; /* 约 36 个汉字 */
	line-height: 1.9;
	letter-spacing: 0.02em;
}

.prose p {
	margin-block: 0 1.1em;
	text-wrap: pretty; /* 避免末行孤字 */
}
```

## 三个数的对照

| 参数 | 建议值 | 失衡后的症状 |
| :-- | :-- | :-- |
| 行宽 | 30–40 汉字 | 串行、读不下去 |
| 行高 | 1.8–1.9 | 闷、糊成一团 |
| 字重 | 400 正文 / 600 标题 | 层次消失，全靠加粗救 |

> 排版不是装饰，是让读者忘记排版。

剩下的都是细节：数字用等宽对齐、西文与中文之间留一点空隙、链接下划线不要贴字、代码块别用纯黑背景。这些加起来，才叫「读起来舒服」。
