# 改内容的方法

所有文字都在源码里，改完 → `npm run build` → 上传 `dist/` 就生效。

---

## 一、首页那几块文字在哪

文件：`src/pages/index.astro`

打开会看到五个区块，从上到下：

```astro
<section class="home-hero">
	<div class="home-signature">
		<p class="kicker">个人博客 · 自 2026</p>        ← 签名上方那行小字
		<Signature size="xl" loop />                    ← 手写签名（默认 Orivane）
		<p class="home-note">关于工程、阅读与生活。…</p>  ← 签名下方说明
	</div>

	<aside class="motto">
		<p class="motto-label">座右铭</p>
		<h1>把复杂的东西，<br />写得让人愿意读完。</h1>   ← 座右铭正文
		<p class="motto-cite">写完自己愿意再读一遍</p>     ← 座右铭下方那行小字
	</aside>
</section>
```

改法：

| 想改什么 | 改哪一行 |
| :-- | :-- |
| 座右铭 | `<h1>` 里那句，`<br />` 是强制换行，可以删 |
| 座右铭下方小字 | `<p class="motto-cite">` |
| 签名上方的说明 | `<p class="kicker">` |
| 签名下方的说明 | `<p class="home-note">` |
| 签名文字本身 | 给组件加参数：`<Signature text="你的名字" size="xl" loop />` |
| 不想要循环动画 | 删掉 `loop` |
| 底部的「最近更新」列表 | 标题在 `<h2 id="recent-title">`，条数在上方代码里 `posts.slice(0, 6)` 的 `6` |


## 三、写一篇新文章

**1. 在 `src/content/blog/` 新建一个 `.md` 文件**，文件名就是网址：

```
src/content/blog/my-first-note.md   →   /blog/my-first-note/
```

> 文件名用**英文小写 + 短横线**（`chinese-typography`、`reading-2026`）。
> 用中文做文件名也能跑，但网址会变成一串 `%E4%B8%AD…`，又长又难分享。

**2. 开头必须有这一段（frontmatter）**：

```yaml
---
title: '文章标题'
description: '一句话摘要，会出现在列表和搜索结果里。'
pubDate: '2026-11-22'
category: '随笔'
tags: ['读书', '生活']
---
```

- `pubDate` 必须是 `年-月-日` 这种格式，**别写 `11月22日`**，解析不了
- `category` 可以省略（默认「未分类」）
- `tags` 可以省略（默认空）

**3. 正文直接写 Markdown**：

```markdown
正文段落之间空一行。

## 一级分节（前面会自动带一条强调色短线）

### 次级标题

> 引用
```

**4. 想先藏着不发**：加一行 `draft: true`，它只在你本地 `npm run dev` 时出现，正式构建不会生成页面。

## 四、加一个新的文章类别

**不用改代码，也不用建文件。** 类别就是 `category` 这个字段的值：

```yaml
category: '影评'
```

- 第一篇写 `影评` 的文章一出现，`/categories/影评/` 这个页面就自动有了
- 总览页 `/categories/` 会自动按篇数排序
- 导航里的「分类」一直指向总览页，不用动

也就是说，你能用的类别没有上限，随便起名：随笔、读书、影评、摄影、折腾、面试……

如果想给类别加一段说明文字，告诉我，我给它加个字段。

## 五、文章里放图片

最省事的做法：

1. 图片丢进 `public/images/`（没有就新建）
2. 正文里写：

```markdown
![图片说明](/images/某个文件名.jpg)
```

路径以 `/` 开头，代表站点的根目录。这样不用管相对路径，也不会在构建时被重命名。

## 六、改完怎么上线

```powershell
npm run build
```

然后把 `dist` **里面的内容**重新上传到 Cloudflare 项目 `orivane-blogs`（Deployments → Create new deployment → 拖进去）。

本地预览不用 build，`npm run dev` 边写边看就行，`localhost:4321` 会自动刷新。

## 七、常见错误

| 现象 | 原因 |
| :-- | :-- |
| 文章没出现 | `draft: true` 没删；或文件名后缀不是 `.md`/`.mdx` |
| 构建报错 `pubDate` | 日期写成了 `2026/11/22` 或 `11月22日`，要 `2026-11-22` |
| 标题里有英文单引号 | YAML 用单引号包裹时，内部的 `'` 要写成两个 `''`，或者整段用双引号 |
| 图片不显示 | 路径没以 `/` 开头，或图片没放进 `public/` |
| 改完线上没变 | 忘了重新 `npm run build` + 上传 `dist` |
| 中文排版变回黑体 | 霞鹜文楷的 CDN 没加载出来，刷新或换网络重试 |
