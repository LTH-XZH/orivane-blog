中文网页排版笔记

大多数「不好读」的中文网页，问题不在审美，在三个数字。

中文和英文的排版，并不是同一套参数换一个字号。英文靠单词之间的空格切分节奏，中文是一块一块的方块字，一旦行宽、行高、字重没调好，整页就会呈现出一种「糊」的感觉——字都认识，但读三行就想划走。

行宽决定一切

西文排版里有个经验值：每行 45–75 个字符。中文没有空格，换算过来大约是 30–40 个汉字。对应到 17px 的字号，就是 600px 上下的正文宽度。超过这个数，眼睛回到行首时容易串行；低于 25 字，换行太频繁，节奏被切碎。

所以正文容器写 max-width: 36em 就够了，不要让它跟着屏幕一起撑满。

排版不是装饰，是让读者忘记排版。

—— 某个深夜改 CSS 的人

行高与段距

中文的「字面率」比英文高，同样的行高在中文里显得更挤。正文行高给到 1.8 到 1.9 之间，段间距一个字高左右，阅读节奏就顺了。

还有一条常被忽略：网页不要首行缩进。缩进是纸质书为了节省纸张形成的习惯，屏幕上有段间距做分隔，再缩进只会多出一个视觉缺口。

:root {
  --measure: 36em;   /* 约 36 个汉字 */
  --leading: 1.85;
  --step: 17px;
}

.prose p {
  margin-block: 0 1.1em;
  text-wrap: pretty;  /* 避免末行孤字 */
}

三个数字的对照

参数建议值失衡后的症状
行宽30–40 汉字串行、读不下去
行高1.8–1.9闷、糊成一团
字重400 正文 / 600 标题层次消失，全靠加粗救

剩下的都是细节：数字用等宽对齐、西文与中文之间留一点空隙、链接下划线不要贴字、代码块别用纯黑背景。这些加起来，才叫「读起来舒服」。
